## Harness
- tests/e2e/lib.mjs (withGame/forEachViewport/check/report, g.tapObject/tapTile/teleport/setInventory/chatCount/trackMoves) is the base for NEW scripts: copy TEMPLATE.e2e.mjs (orbs.e2e.mjs = reference, :5205, ~25 s). Pass forEachViewport(...) result AS the withGame callback; withGame exits the process itself. g.rect() returns CENTRE x,y (+left/top/w/h): don't add w/2. g.state() = game slice, g.store() = ROOT. targets() covers WORLD_TREES/OBJECT_SPAWNS/NPC_SPAWNS but NOT rocks or fishing spots. setInventory REPLACES inventory (include the tool). g.eval returning a Phaser object throws "reference chain too long": append `, 0`. g has no cdp handle: g.screenshot + SHOTS_DIR. Store expr scope is `s`.
- cdp.mjs watchdogs: E2E_MAX_MS 6 min -> exit 3, E2E_IDLE_MS 120 s -> "E2E STUCK" exit 4, 20 s per-send timeout (E2E_CDP_TIMEOUT_MS), Chrome exit rejects pendings; exports runMain/waitFor/activity. Never pkill in proofs. Top-level await on a never-resolving promise exits 13: keep a timer alive to test watchdogs.
- launchChrome() takes no flags; a real CDP mouse press is a valid gesture (no autoplay flag). Node 20.18 has no global WebSocket (raw fallback). Phaser 3.90: no Phaser.GAMES; capture the game by wrapping window.Phaser setter, or use window.__idleRpg (store, scene(), setTickMs). scene().camera.scene = WorldScene (vfx, buildings, views, nodes, animator, game reachable); Phaser game = scene().camera.scene.game (loop.sleep/wake freezes a frame).
- CDP quirks: Target.setDiscoverTargets replays the existing page (only close targets with openerId); about:blank localStorage throws SecurityError (clear after navigating); noopener tab reports url "" at targetCreated; setTouchEmulationEnabled needs maxTouchPoints>=1 even when disabling; Browser.setWindowBounds needs clearDeviceMetricsOverride first; headless window height != viewport; no 2nd-tab API: use a same-origin iframe as "tab B" (saves). Count listener leaks by wrapping EventTarget add/removeEventListener in addScriptToEvaluateOnNewDocument.
- Phone = Emulation.setDeviceMetricsOverride mobile + setTouchEmulationEnabled + Input.dispatchTouchEvent (900 ms hold = long-press). CDP touch long-press does NOT fire native contextmenu (hold ends as tap): dispatch a `contextmenu` MouseEvent on the element. dpr capped at 2. Desktop canvas is 998 px (HUD beside it): use the canvas rect. Phone canvas ~480 css px tall: tiles >=3 ahead go off-canvas / under HUD (iso ~48 px/tile): teleport/step near first, tap in 1-2 tile hops. A canvas tap also WALKS the player (teleport back, settle).
- Tick control: `?tickMs=60` (10x), `__idleRpg.setTickMs(600)` for real-time checks (g.realTime), setTickMs(3600000) freezes for close-ups. Sessions end in ~1 s at 60 ms: wrap in g.realTime or keep-alive re-interact (setInterval) and run each mode phase in its own keep-alive gather. Sound minGapMs is real time. Teleport via store.setState: minimap trail glides ~2 s; same-tile teleport does not recentre follow camera; load() after teleport can keep the old tile.
- Camera settle = lib waitStill(sample) (150 ms between samples, 2 stable intervals); two reads in one rAF look stable while easing. Iso tap point = isoProjection.tileToWorld + camera toClient (window.__e.toClient). Re-sample then tap immediately (canopies sway, points drift).
- Spawn 18,15 is free ground; tile 40,40 blocked taps; fixture tile (12,9) blocked in big world -> loads at spawn.
- Pixel work: decode captureScreenshot in-page; clip {scale} around toClient; sips -c H W --cropOffset y x then sips -z (no PIL). Wrap in-page rAF samplers in try/catch. Spy browser APIs via addScriptToEvaluateOnNewDocument (guard P.__spied): fillText (minimap labels, last frame = after last clearRect), drawImage (worldmap), createOscillator/createBiquadFilter (audio).
- Audio: Phaser has its OWN AudioContext, game's identified by wrapping createDynamicsCompressor; hook AudioNode.connect to find master gain; assert area change via fade-in ramps not osc counts. Axe hit = triangle 105-230 only; music chords are sine 485-550; ambience beds identified by BiquadFilter type:freq.
- Prefs storage `{version, prefs}` written only on first change. Selectors: [data-slot-index=N], [role=menu], .menu-item, .slot[data-selected], .use-hint, [role=dialog][aria-label=Bank] (Close button text), img.dialogue-avatar-img, .dialogue-main/.dialogue-choice/.dialogue-rest, radios via radiogroup aria-labelledby text (scrollIntoView then real tap), canvas.minimap. Bank slots by aria-label. `data-folded`/`data-min` read true on desktop even when expanded: assert desktop layout via computed style. Phone panel scrolls inside .hud-body (assert rect within innerHeight). `pointer-events:none` on a button = tap falls through. Native `disabled` button swallows taps. Inventory tab active at boot: tapping the ACTIVE tab collapses the panel. On phone the bank panel covers most of the canvas.
- Back/front facing: force it through the animator API (or wrap pv.setBackView in-page to read); walking to a tree does not control arrival facing.
